# WorkMate AI — AI-Powered Workplace Productivity Assistant

## Project Overview
WorkMate AI is a student project prototype that demonstrates how generative AI and prompt engineering can support common workplace tasks. The assistant focuses on four practical workflows:

1. Email generation
2. Meeting summarisation
3. Task planning
4. Research assistance

The project also demonstrates responsible AI principles including human review, privacy awareness, and fact verification.

## Objectives
- Demonstrate practical use of AI in the workplace.
- Apply structured prompt engineering.
- Build a functional, responsive user interface.
- Show how AI can reduce repetitive work while keeping people in control.
- Communicate limitations and responsible-use considerations.

## Features
### Email Generator
Turns rough notes into a professional workplace email.

### Meeting Summarizer
Converts notes into decisions, action items, owners and follow-up points.

### Task Planner
Breaks a goal into prioritised steps and a suggested next action.

### Research Assistant
Structures a research question, suggested research angles and an evidence checklist.

### Prompt Engineering
Demonstrates a reusable prompt structure:
- Role
- Context
- Task
- Constraints
- Output format
- Quality check

### Responsible AI
Highlights:
- Privacy
- Human oversight
- Accuracy and fact checking

## Prompt Engineering Example
```text
Role: Workplace productivity assistant.
Context: [audience + background + source notes]
Task: [specific action]
Constraints: [tone + length + exclusions]
Output: [exact structure]
Quality check: Identify missing information and assumptions before finalising.
```

## Responsible and Ethical AI
AI outputs should be treated as drafts rather than unquestionable facts. Users should avoid entering confidential or sensitive information into tools unless the organisation has approved that use. Important emails, decisions, research claims and external communications should be reviewed by a person.

## Limitations
This submission is a front-end prototype. The demo uses JavaScript-generated sample outputs rather than a live external AI API. This keeps the prototype self-contained and avoids exposing API credentials in client-side code.
