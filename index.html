Prompt Engineering

The assistant uses structured prompts rather than vague instructions.

1. Role

Tell the model what expert perspective it should use, e.g. “Act as a professional workplace communications assistant.”

2. Context

Provide the audience, purpose, background, constraints and source material.

3. Task

State exactly what should be produced. Avoid ambiguous verbs such as “fix this” without context.

4. Output format

Specify structure, length, tone, headings, bullets or tables so results are consistent.

Example prompt pattern

Role: Workplace productivity assistant. Context: [audience + background + source notes] Task: [specific action] Constraints: [tone + length + exclusions] Output: [exact structure] Quality check: Identify missing information and assumptions before finalising.

Responsible AI

Useful automation still needs human oversight.

🔐 Privacy

Do not paste confidential, personal or sensitive information into tools unless approved by the organisation.

👤 Human oversight

AI drafts should be reviewed by a person before important messages, decisions or external publication.

✓ Accuracy

Verify facts, dates, names, calculations and research claims. AI can produce plausible errors.

Project success criteria

Practical value • clear prompts • functional interaction • transparent limitations • ethical safeguards • understandable documentation.
